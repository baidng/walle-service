# walle-ai 树莓派小车远程控制平台

walle 是一个面向树莓派小车的远程控制平台：通过 **MQTT** 下发控制指令、接收设备状态与告警，通过 **流媒体服务** 实时查看车载画面，并用一个统一的 Web 门户完成登录、监控与管理。

## 功能

**统一门户**

- 单入口 Web 界面（默认 `http://<host>:8088/`），管理员与普通用户分角色进入
- 账号由后端统一校验，登录失败给出明确提示，退出后清除登录态

**管理员控制台**

- 基本信息：EMQX 节点、在线客户端数、SRS 版本、活动流数量，服务状态一览
- MQTT：连接/订阅数、消息吞吐趋势、主题规范说明、用户与规则引擎（规划中）
- SRS：活动流列表、观看人数、收发带宽、服务配置查看
- 系统设置：版本、时区、License 信息与维护动作（部分为规划项）

**普通用户控制台**

- 我的设备：设备卡片列表，展示在线状态、电量、位置与推流地址
- 设备信息：设备 ID、状态、电量、位置、MQTT 主题前缀、拉流地址
- 实时监控：页面内直接播放车载画面（HTTP-FLV），支持手动重连
- 运动控制：前进/后退/转向/停止，以及录像、模式切换、鸣笛、灯光等指令入口
- 录像与告警：按设备回看录像、查看碰撞/低电量/离线等事件（规划中）

**设备接入**

- MQTT 主题按 `walle/{device_id}/{cmd|state|alarm|heartbeat}` 划分
- 视频经 RTMP 推流接入，统一以 HTTP-FLV / HLS / WebRTC 分发

## 快速开始

1. 部署服务端（EMQX + SRS + 门户）：见 [walle服务端部署文档](docs/walle服务端部署文档.md)
2. 浏览器打开 `http://<host>:8088/`，用后端账号登录
3. 设备侧按主题规范接入 MQTT，并向 `rtmp://<host>:1935/live/{stream}` 推流
